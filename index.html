What this is

A workshop collection for systematic token naming

This site gathers a written handbook and interactive HTML tools that teach the same idea: token names should encode where something lives, what it does, and how it relates to everything else.

Built for designers, engineers, and design-system leads who want naming decisions that scale — and stay legible to both humans and LLMs.

How to use it

Read first, practice in layer order

Work through the material as a path, not a grab-bag. Keep the reference card open while you exercise.

  1. Read the handbook Start with Systems Thinking and Token Naming — or download the PDF.
  2. Keep the reference card nearby Open the naming reference card for mental models, tiers, domains, and failure modes.
  3. Practice Layer 2 → 4 Use the anatomy mapper, then the three-tier chain builder, then the naming worksheet.
  4. Build your convention Define axes and export stubs with the token naming builder.

Tools

Hands-on workshop exercises

Self-contained HTML tools — open any of them directly in the browser.

  • Workshop reference
    Design system naming reference card →

    Complete reference covering all six workshop layers — mental models, tiers, domains, anatomy, questions, and failure modes.
  • Workshop tool Layer 2
    Component anatomy mapper →

    Map a component’s parts, properties, and states — then watch token names generate live from [component]-[part]-[property]-[state].
  • Workshop tool Layer 3
    Three-tier token chain builder →

    Build a complete token chain from primitive → semantic → component, with live visualization and tier validation.
  • Workshop tool Layer 4
    Token naming worksheet →

    Answer six questions for any token. The decision record assembles as you type — copy or download it into your docs.
  • Workshop tool Axis builder
    Token naming builder →

    Define the axes that make up your token names, populate categories, and export a naming convention reference plus DTCG-shaped JSON and CSS stubs.
  • Workshop tool Value editor
    Token value builder →

    Import naming-builder tokens, fill typed DTCG and Terrazzo values, preserve aliases, and export completed JSON.
