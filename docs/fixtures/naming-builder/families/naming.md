# Tier 1 · Primitive Naming Convention

## Axes

1. **namespace** (optional)
2. **category** (required)
3. **family**
4. **scale** (required — final axis)

## Formula

```
[namespace]-[category]-[family]-[scale]
```

## Namespace

**ds** (global — applies to all tokens)

## Categories

### border

- **Token type**: `dimension`
- **family** (branched)
  - **radius**
    - **Token type**: _not set_
    - **scale** (T-shirt sizes): xs, sm, md, lg, xl
  - **width**
    - **Token type**: _not set_
    - **scale** (Numeric range): 1, 2, 3, 4
