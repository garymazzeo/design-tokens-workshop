Step 1 Define your axes

Token names follow a fixed structure: category and scale are required. Namespace is optional and comes first when enabled. Add other axes (e.g. family) between category and scale.

Step 2 Add categories & populate axis values

Each category (color, space, font-size…) gets its own values for each axis and a token type (category name ≠ type — e.g. space → dimension). Category and scale are always configured here. Namespace is set once in Step 1 and applies to all tokens. Set an axis to Unused when it doesn't apply — e.g. space usually has no family axis. Use Branch this axis when sibling paths need different scales (e.g. border-radius vs border-width).

Step 3 Review & export

Preview names live. Export CSS stubs, a markdown convention, or DTCG-shaped JSON (group $type + leaf descriptions — not import-ready values).
